# 💱 Currency Converter

A modern, responsive web application for real-time currency conversion and exchange rate tracking. Built with vanilla JavaScript and featuring a clean, professional interface inspired by leading financial platforms.

## 🚀 Quick Start

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/tinn1855/currency-converter.git
   cd currency-converter
   ```

2. **Start a local server**

   Using Live Server (VS Code)

   - Install Live Server extension
   - Right-click on `index.html` → "Open with Live Server"

3. **Open in browser**
   ```
   http://localhost:8000
   ```

## 🛠️ Technologies Used

### Frontend

- **HTML5**: Semantic markup with modern standards
- **CSS3**: Flexbox, Grid, Custom Properties, Animations
- **Vanilla JavaScript (ES6+)**: Modules, Classes, Async/Await
- **Font Awesome**: Icons and visual elements
- **Google Fonts**: Quicksand typography

### APIs

- **ExchangeRate-API**: Real-time currency exchange rates
- **REST API**: RESTful architecture for data fetching

## 📱 Responsive Design

The application is fully responsive with breakpoints:

- **Desktop**: 1200px+ (Full layout)
- **Tablet**: 768px - 1199px (Adjusted layout)
- **Mobile**: Below 768px (Stacked layout, horizontal scroll)

## 🎯 Usage Examples

### Basic Currency Conversion

1. Enter amount in the input field
2. Select "From" currency
3. Select "To" currency
4. View instant conversion result

### Currency Search

1. Use the search box above the currency table
2. Type currency name or code
3. Results filter in real-time

### Pagination Navigation

- Use numbered buttons to navigate pages
- First/Previous/Next/Last buttons for quick navigation
- Ellipsis (...) indicates additional pages
